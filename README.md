## ⚡ Overview

A high-impact interactive 3D portfolio engineered for **Reuben Kimani** — Full-Stack Software Engineer, AI Systems Architect, and Founder of LQD Creative.

Inspired by cutting-edge creative developer showcases ("YOUR PORTFOLIO HAVE EMOTIONS"), this application features a real-time **3D Male Avatar Emotional Engine** with mouse gaze tracking, dynamic comic thoughts, interactive mood switching, and full cloud integration powered by **Supabase** and deployed on **Vercel**.

---

## 🚀 Key Features

- **🎭 3D Male Avatar Emotional Engine:**
  - 6 pixel-consistent 3D rendered emotional states: *Confident*, *Wink*, *Inspired*, *Zen*, *Playful*, and *Impressed*.
  - Real-time 3D mouse parallax tracking (`perspective(1200px) rotateX(...) rotateY(...)`).
  - Interactive speech bubbles and mood control bar.
  - Optional sound frequency tones for tactile sensory feedback.
- **🛹 Infinite Project Marquee (Frame 07):** Dual-row infinite sliding cards showcasing engineering work with hover-pause.
- **🎨 Elevated Services Section (Frames 08 & 09):** Curved contrasting card container with 3D extruded typography and vibrant numbered pillars (01 Full-Stack, 02 AI Automation, 03 Brand Architecture, 04 Cloud & Cyber Infrastructure).
- **💼 Bento Featured Projects (Frame 11):** High-density cards with live telemetry tags, multi-frame previews, and direct live links (Project SafeNet OS, VibeFi Hotspot OS, Cisco Academy Progress Tracker, LQD Creative Agency).
- **⚡ Live Supabase Telemetry & Reactions:** Real-time emoji reaction counters with confetti physics synchronized to PostgreSQL.
- **📖 Live Visitor Guestbook:** Interactive community kudos board writing directly to Supabase.
- **📬 Supabase Contact Engine:** Direct project brief transmission to Supabase, paired with one-tap WhatsApp and Voice call triggers to `0740396075`.

## 🛠️ Tech Stack

- **Frontend:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Lucide React, Canvas Confetti
- **Backend / Database:** Supabase (PostgreSQL with Row Level Security)
- **Deployment & CDN:** Vercel Global Edge Network
- **Version Control:** GitHub (`wanjikudigitaldesignservices-cyber/reuben-kimani-portfolio`)

## 📦 Local Development

```bash
# Clone the repository
git clone https://github.com/wanjikudigitaldesignservices-cyber/reuben-kimani-portfolio.git
cd reuben-kimani-portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
